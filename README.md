# music.harshdeepsingh.in

Personal website for Harshdeep.

Built with Next.js, Tailwind CSS, and OpenNext for Cloudflare Workers.

## Deployment (Cloudflare Workers)

The site is deployed to Cloudflare Workers at https://music.harshdeepsingh.in.

### Commands

```bash
# Local development
npm run dev

# Build for Cloudflare Workers
npm run cf-build

# Local preview with Wrangler
npm run preview

# Deploy to Cloudflare Workers
npm run deploy
```
